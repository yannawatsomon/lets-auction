# Glossary

Terms that are easy to misread, especially across Thai/English. Add as you go.

| Term | Thai | Meaning in this project |
|---|---|---|
| context | บริบท | Background an agent needs before acting (`ai/context/`) |
| credit grade | เกรดเครดิต | A–E grade from the lets-auction score (0–100); decides which auctions a buyer can join (`docs/decision/user-onboarding.md`). Not a credit bureau (NCB) score |
| decision | การตัดสินใจ | A recorded choice with reason and trade-off (`docs/decision/`) |
| onboarding | การลงทะเบียนยืนยันตัวตน | The 4 steps a buyer completes before joining any auction: national ID + phone, employment, score, confirm |
| skill | สกิล | A reusable instruction package an agent can follow (`.claude/skills/`) |
