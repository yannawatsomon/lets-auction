# Playbook: new feature

A suggested flow, not a requirement. Use what helps.

1. **Issue** — open (or pick) a GitHub issue using the Feature template. Say what and why.
2. **Branch** — `<github-handle>-feat-<issue>-<short-name>` from latest `main`
   (the issue number comes from step 1).
3. **Build** — small commits, with tests.
4. **PR** — fill in the PR template and link the issue (and any decision docs it touches).
5. **Merge** — squash-merge once CI is green; delete the branch.
